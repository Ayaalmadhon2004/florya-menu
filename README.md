# Florya: قائمة طعام رقمية (QR Menu)

قائمة بتصميم كلاسيكي للمطاعم والكافيهات. الزبون يمسح QR على الطاولة، يقلّب القائمة مثل كتاب، ويبعت طلبه على واتساب.

## المميزات
- عربي / English مع RTL كامل وتبديل لغة فوري
- طلب عبر واتساب برقم الطاولة (أو سفري) مع كميات وملاحظات
- **منيو قلاب (Flipbook)**: صفحات ثلاثية الأبعاد تنقلب حول عمود الكتاب، بالسحب أو الأزرار أو الأسهم، واتجاه القلب يتبع اللغة (يمين لليسار بالعربي)
- صفحة فهرس للقفز مباشرة لأي قسم
- صفحة طباعة أكواد QR لكل الطاولات: `/qr?tables=20`
- تعمل كتطبيق على الجوال (PWA manifest)، سريعة، موقع ثابت (استضافة مجانية)

## التسليم لعميل جديد (10 دقائق)
1. `src/config/restaurant.ts` — الاسم، رقم واتساب، العنوان، الساعات، العملة.
2. `src/data/menu.ts` — الأقسام والأصناف والأسعار والصور.
3. `src/app/globals.css`: لون العلامة (`--color-burgundy`) واللون الذهبي (`--color-gold`).
4. صورة غلاف المطعم: غيّريها في `coverImage` داخل ملف الإعدادات (رابط أو صورة داخل `public/`). الصورة تظهر خلف الغلاف بشفافية خفيفة، وإن لم تتحمّل يظهر اللون النبيذي.
5. `npm run build` ثم ارفع مجلد `out/` على Netlify / Vercel / Cloudflare Pages.

## التشغيل
