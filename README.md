## لماذا هذا المنيو؟

القائمة الورقية تتمزق وتتغير أسعارها وتحتاج طباعة من جديد. وتطبيقات الطلب الكبيرة تأخذ عمولة من كل طلب.

هذا المنيو يحل الاثنين بشكل بسيط:

- **تعديل الأسعار في دقيقة.** تغيّر السطر في ملف واحد وتنشر من جديد.
- **الطلب يصلك مباشرة.** رسالة واتساب جاهزة فيها الأصناف والكميات والإجمالي ورقم الطاولة، من غير وسيط ولا عمولة.
- **شكل يليق بالمطعم.** صفحات تنقلب فعلاً، وخطوط كلاسيكية، وألوان ذهبية ونبيذية، وصورة غلاف من مطعمك.
- **يشتغل على أي جوال.** يفتح من المتصفح مباشرة، وسريع لأنه موقع ثابت.

## كيف يعمل؟

| الخطوة | ماذا يحدث |
|---|---|
| **1. يمسح** | الزبون يمسح الـ QR الموضوع على طاولته، فيفتح المنيو ومعه رقم الطاولة. |
| **2. يقلّب ويختار** | يقلّب الصفحات، يضيف الأطباق، يغيّر الكميات، ويكتب ملاحظته مثل "بدون بصل". |
| **3. يرسل** | زر واحد يفتح واتساب برسالة جاهزة إلى رقم المطعم. أنت تحضّر الطلب وتخدمه. |

## المميزات

### تجربة الزبون
- **منيو قلاب (Flipbook):** صفحات ثلاثية الأبعاد تنقلب حول عمود الكتاب. تنقلب بالسحب أو بالأزرار أو بأسهم الكيبورد، أو بالقفز من صفحة الفهرس.
- **عربي وإنجليزي:** تبديل فوري بزر واحد، ودعم كامل للكتابة من اليمين لليسار. حتى اتجاه قلب الصفحة ينعكس مع اللغة.
- **سلة طلبات:** كميات، ملاحظات، اختيار "داخل المطعم" أو "سفري". السلة تبقى محفوظة لو أغلق الزبون الصفحة بالغلط.
- **رسالة واتساب مرتبة:** فيها الأصناف والكميات والإجمالي والملاحظات ورقم الطاولة. تعمل مع النص العربي والرموز الخاصة بدون تشويه.
- **حركة ناعمة:** انتقالات وحركات خفيفة، وتتوقف تلقائياً عند الزبون الذي فعّل "تقليل الحركة" في جواله.

### لصاحب المطعم
- **ملفان فقط للتعديل:** إعدادات المطعم، وقائمة الأطباق.
- **صورة غلاف قابلة للتبديل:** صورة حقيقية من مطعمك تظهر بشفافية خفيفة خلف الاسم.
- **علامات على الأطباق:** الأكثر طلباً، جديد، نباتي، حار، ونفد (يخفي زر الإضافة مؤقتاً).
- **صفحة طباعة QR:** كود لكل طاولة جاهز للطباعة.
- **بدون قاعدة بيانات ولا خادم:** موقع ثابت يُستضاف مجاناً.

## تجهيز مطعم جديد

كل شيء يتغير من ثلاثة أماكن فقط.

### 1. بيانات المطعم: `src/config/restaurant.ts`

| الحقل | ما هو |
|---|---|
| `name`, `type`, `tagline` | الاسم والنوع والشعار، بالعربي والإنجليزي |
| `whatsapp` | رقم الواتساب بصيغة دولية بدون `+` ولا أصفار، مثل `966501234567` |
| `phone`, `instagram`, `address`, `hours`, `mapsUrl` | بيانات التواصل |
| `currency` | العملة، مثل `ر.س` و`SAR` |
| `defaultLang` | لغة البداية: `"ar"` أو `"en"` |
| `coverImage` | صورة الغلاف: رابط، أو ملف داخل `public/` مثل `"/cover.jpg"`. اتركها فارغة لتظهر خلفية نبيذية فقط |
| `siteUrl` | رابط الموقع بعد النشر، يُستخدم في أكواد QR |

> نصيحة لصورة الغلاف: عرض 900px أو أكثر، وحجم أقل من 300KB، ويفضّل صورة داخلية دافئة الإضاءة للمطعم.

### 2. الأطباق والأسعار: `src/data/menu.ts`

كل قسم فيه عنوان ووصف قصير وقائمة أطباق. وكل طبق بهذا الشكل:

```ts
{
  id: "m1",
  name: { ar: "ستيك أنغوس", en: "Angus Steak" },
  description: { ar: "على الفحم مع صوص الفلفل الأسود", en: "Charcoal grilled, black pepper sauce" },
  price: 129,
  image: "/dishes/steak.jpg",   // رابط أو ملف داخل public/
  badges: ["hot"],              // "hot" | "new" | "veg" | "spicy"
  soldOut: false,               // true لإخفاء زر الإضافة مؤقتاً
}
```

### 3. الألوان: `src/app/globals.css`

غيّر `--color-burgundy` للون العلامة التجارية، و`--color-gold` للون الزخارف. وغيّر `themeColor` في ملف الإعدادات ليطابقه.

## التشغيل على جهازك

المطلوب: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. ولتجربة رقم طاولة افتح `http://localhost:3000/?table=5`.

للتأكد من سلامة المشروع قبل النشر:

```bash
npm run lint
npm run build
```

## النشر

المشروع يُبنى كموقع ثابت داخل المجلد `out/`، فيصلح على أي استضافة مجانية:

```bash
npm run build
```

ثم ارفع المجلد `out/` على **Netlify** أو **Vercel** أو **Cloudflare Pages** أو **GitHub Pages**، أو اربط الريبو مباشرة واجعل أمر البناء `npm run build` ومجلد النشر `out`.

بعد النشر ضع رابط الموقع في `siteUrl` داخل ملف الإعدادات، ثم ابنِ ونشر مرة ثانية.

## أكواد QR للطاولات

افتح `/qr?tables=20` على موقعك المنشور (غيّر 20 إلى عدد طاولاتك) واضغط **طباعة**. كل كود يفتح المنيو ومعه رقم الطاولة، فيصل الطلب إلى واتساب وفيه رقم الطاولة مكتوباً.

## أسئلة شائعة

**هل يحتاج الزبون لتحميل تطبيق؟**
لا. يفتح من المتصفح مباشرة بعد مسح الـ QR.

**هل الطلبات تُخزَّن في مكان ما؟**
لا. الطلب يُرسل كرسالة واتساب إلى رقم المطعم فقط، والمنيو لا يحتفظ ببيانات الزبائن. السلة تُحفظ في جوال الزبون نفسه.

**هل يدعم الدفع الإلكتروني؟**
ليس حالياً. الدفع يتم في المطعم كالمعتاد.

**كيف أغيّر الأسعار لاحقاً؟**
عدّل الرقم في `src/data/menu.ts`، ثم `npm run build` وارفع `out/` من جديد.

**هل أستطيع إضافة لغة ثالثة؟**
ممكن، لكنها تحتاج إضافة نصوص اللغة في `src/lib/i18n.ts` وفي بيانات المطعم والأطباق. اطلب ذلك كتعديل إضافي.
